FLOWATLAS / EXPLORER

Une carte honnête. Même dans ses silences.

Une relation doit pouvoir se justifier dans le code. Quand une liaison est dynamique ou impossible à résoudre statiquement, FlowAtlas ne l’invente pas.

Deux branches asynchrones peuvent rejoindre le même état sans former une chaîne causale démontrable. La carte préserve cette distinction.

Explorer un premier événement +

Recherchez un élément avec find, puis utilisez son identifiant exact pour ouvrir la carte : 

node dist/index.js find like /chemin/vers/votre-projet
node dist/index.js tui <nodeId> /chemin/vers/votre-projet

Le projet analysé doit contenir un tsconfig.json. Les motifs Redux Toolkit pris en charge sont décrits dans le dépôt.
